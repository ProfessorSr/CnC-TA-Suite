# ADR-0001: Page-context application with storage bridge

> Status: Accepted

## Context

The suite needs direct access to game-owned ClientLib and Qooxdoo globals, while Chrome storage is available only to extension contexts.

## Decision

Run the suite as an injected page-context ES module. Keep a minimal content script that injects approved resources and brokers storage requests over a namespaced, request-ID-based `window.postMessage` channel.

## Consequences

Game APIs are directly available and storage remains persistent. Modules share the page's trust boundary and are not a security sandbox; all bundled code requires review. The bridge must keep operations narrow and validate message source, channel, direction, and operation.
