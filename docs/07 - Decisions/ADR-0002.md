# ADR-0002: Native Qooxdoo user interface

> Status: Accepted

## Context

An independent DOM window system looked inconsistent, could be covered by the game, and did not share native focus, theme, or widget behavior.

## Decision

Use game-provided Qooxdoo widgets for in-game windows, dialogs, notifications, controls, menus, and top-bar actions. `WindowManager` accepts Qooxdoo widgets or strings, not raw HTML elements.

## Consequences

Suite UI matches the game and participates in its layout/focus system. Bootstrap must wait for Qooxdoo, UI code depends on compatible qx APIs, and widgets/listeners require explicit destruction. DOM UI remains limited to browser injection needs.
