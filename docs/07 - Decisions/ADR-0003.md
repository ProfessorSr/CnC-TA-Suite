# ADR-0003: Build-time module discovery

> Status: Accepted

## Context

Browser extensions cannot enumerate source directories at runtime, while maintaining a manual module import list is error-prone.

## Decision

The build scans immediate `modules/` directories, locates a module entry/class, and writes `core/modules/moduleCatalog.generated.js`. Startup instantiates classes from that catalog before enabling configured modules.

## Consequences

Adding a valid module directory is sufficient, builds are deterministic, and missing imports are caught early. Developers must rebuild after module changes and must not edit the generated catalog. Runtime-downloaded plugins remain unsupported.
