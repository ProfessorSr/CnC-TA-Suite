## Required live acceptance before tagging

EA's client is obfuscated and runtime-dependent, so automated tests cannot prove
live compatibility. Before tagging v1.0.0, load `dist/chrome` and complete the
checklists under `tests/integration/`, including:

- clean bootstrap with no Suite fatal error;
- enable/disable persistence and disabled-module UI cleanup;
- right dock, base-view controls, top bar, and window open/close behavior;
- current-base and current-target synchronization through the Hub;
- War Room native simulation and replay;
- explicit confirmation and correct result reporting for each tested native
  repair, upgrade, transfer, support, or formation action;
- diagnostic export redaction and absence of repeated hooks/listeners;
- acceptable performance on an account with multiple bases.

Browser permissions-policy and `blank.gif` messages originating in the EA client
are not Suite failures unless accompanied by broken Suite behavior.

## Decision

The source may be committed as a v1.0.0 release candidate after repository
validation passes. Create the public tag only after the live acceptance pass and
after confirming there are no known critical or high-severity defects.
