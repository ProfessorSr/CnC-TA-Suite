# Design System

> Status: Baseline for v0.4.0

The design system is the game's Qooxdoo theme plus suite interaction rules. Use native widget appearances, 4–10 px layout spacing, clear information hierarchy, short action labels, tooltips for unfamiliar controls, and scroll containers for variable content. Primary entry is Module Manager in the game navigation. Suite Status and Launcher are on-demand modules. Avoid duplicate launch surfaces, raw DOM windows, decorative animation, or controls that resemble game actions without clear suite labeling.
