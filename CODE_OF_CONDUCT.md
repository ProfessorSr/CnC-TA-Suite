# Code of Conduct

Project spaces must remain respectful, constructive, and focused on improving
CnC-TA-Suite. Harassment, discrimination, threats, publication of private
information, and deliberately disruptive behavior are not accepted.

Contributors should critique ideas and code rather than people, assume good
faith while asking for evidence, and respect maintainers' release, safety, and
scope decisions. Maintainers may edit or remove inappropriate contributions
and restrict participation when necessary.

Report conduct concerns privately through the repository owner's published
GitHub contact channel. Do not include credentials, session data, or private
player information in a public issue.
